# Mockup NiagaERP

Ini adalah mockup modern ERP Perusahaan Dagang. Buka `index.html` dengan Live Server, lalu gunakan tombol dan navigasi untuk mencoba seluruh alur.

Semua halaman berada langsung di folder `mockup/` dan menggunakan aset bersama:

- `assets/app.css` untuk tema, layout, tabel, form, dan responsive UI.
- `assets/app.js` untuk sidebar, topbar, data dummy, dan navigasi modul.
- `assets/print.css` untuk tampilan cetak Delivery Order.

Data pada mockup bersifat statis dan hanya menjadi referensi tampilan untuk implementasi Laravel.
