Events & Forms

Form yang bener + ngambil data dari internet

1. preventDefault() — Stop Form Reload

Default-nya, form yang di-submit akan reload halaman. e.preventDefault() menghentikan itu supaya JavaScript yang ambil alih.

2. Event "submit" — Cara yang Benar

Dengar event submit di form-nya, bukan click di button. Ini juga aktif kalau user tekan Enter, bukan cuma klik tombol.

3. fetch() — Ambil Data dari Internet

fetch() minta data dari server lain (API). Di sini kita ambil fakta kucing random dari API gratis.

4. Loading State & Error Handling

Internet bisa lambat atau gagal. Tampilkan "Loading..." saat nunggu, dan tangkap error kalau gagal pakai try/catch.
