JavaScript Syntax Basics

Click each "Run" button to see the result. Open DevTools (F12) to also see console.log output.

1. Variables

Variables are boxes that store information. Use let for values that can change, const for values that never change.

let name = "Vanya";
const age = 20;
let isStudent = true;

2. Data Types

JavaScript has different types of data: text (string), number, and true/false (boolean).

let text    = "Hello";       // string — always in quotes
let number  = 42;            // number — no quotes
let isTrue  = true;          // boolean — true or false
let nothing = null;          // null — empty on purpose

3. Input & Output

console.log() prints to DevTools. alert() shows a popup. prompt() asks the user to type something.

let answer = prompt("What is your name?");
alert("Hello, " + answer + "!");

4. If / Else

Make decisions in code. "If this is true, do this. Otherwise, do that."

let score = 75;

if (score >= 90) {
  console.log("Grade: A");
} else if (score >= 70) {
  console.log("Grade: B");
} else {
  console.log("Grade: C");
}

5. For Loop

Repeat something a set number of times. "Start at 1, keep going while less than or equal to 5, add 1 each time."

for (let i = 1; i <= 5; i++) {
  console.log("Number: " + i);
}

6. While Loop

Keep repeating as long as something is true. Useful when you don't know how many times upfront.

let count = 1;

while (count <= 3) {
  console.log("Count is: " + count);
  count++;   // count++ means count = count + 1
}

7. Functions

A function is a reusable block of code. Give it a name, call it whenever you need it. Can accept input (parameters) and give back a result (return).

function greet(name) {
  return "Hello, " + name + "!";
}

let message = greet("Vanya");
console.log(message);

8. Arrays

An array is a list of items inside square brackets []. Each item has a position number starting from 0 (not 1).

let fruits = ["apple", "banana", "mango"];

console.log(fruits[0]);        // "apple" (position 0)
console.log(fruits.length);    // 3 (total items)

fruits.push("grape");          // add item to end
console.log(fruits);

9. Objects

An object stores related information together using key: value pairs — like a contact card.

let person = {
  name: "Vanya",
  age: 20,
  isStudent: true
};

console.log(person.name);   // "Vanya"
console.log(person.age);    // 20

Open DevTools (F12 → Console) to see all console.log output too.
