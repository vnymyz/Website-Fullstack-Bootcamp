localStorage

Nyimpen data di browser, nggak hilang pas refresh

1. Simpan & Ambil Teks

localStorage.setItem(key, value) nyimpen data. localStorage.getItem(key) ambil lagi. Coba isi, refresh halaman (F5), lihat teksnya masih ada.

2. Hapus Data

localStorage.removeItem(key) hapus satu data. localStorage.clear() hapus semua data localStorage punya website ini.

3. Simpan Array / Object (JSON)

localStorage cuma bisa nyimpen string. Buat nyimpen array/object, harus diubah jadi string dulu pakai JSON.stringify(), dan diubah balik pakai JSON.parse().

    Buka DevTools (F12) → tab Application → Local Storage untuk lihat data mentahnya
